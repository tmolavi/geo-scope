> این پژوهش، **نخستین بنچمارک تجربی مستقل و داده‌محور** برای ارزیابی هویدایی برندها (AI Visibility)، نرخ پیشنهاد صریح (Explicit Recommendation) و استناد دامنه‌ها در موتورهای هوش مصنوعی مولد برای دو بازار استراتژیک **ایران** و **ترکیه** است.

## ۷. بازتولید و اعتبارسنجی آفلاین

```bash

sha256sum -c benchmarks/regional-commercial-intent-2026.1/checksums.sha256

# بازپخش قطعی و استخراج داده‌ها از شواهد خام
geo-scope replay \
  --archive benchmarks/regional-commercial-intent-2026.1/raw_responses.jsonl \
  --entities benchmarks/regional-commercial-intent-2026.1/entities.json \
  --out-dir /tmp/replay-verification
```
